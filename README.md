# 💰 Discount Calculator (Tkinter)

A simple desktop GUI application built with Python Tkinter that calculates discount based on shopping amount.

---

## 📌 Features
- User enters shopping amount
- Automatic discount calculation:
  - ≥ 3000 → 3% discount
  - ≥ 2000 → 2% discount
  - > 1000 → 1% discount
  - ≤ 1000 → No discount
- Displays discount amount in real time
- Simple and clean GUI interface

---

## 🛠️ Tech Stack
- Python 3
- Tkinter (GUI library)
